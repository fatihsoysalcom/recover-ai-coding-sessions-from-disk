# Recover AI Coding Sessions From Disk

This example demonstrates how to simulate the recovery of AI coding sessions (like Claude and Codex) from raw disk data using Python. It creates a temporary file representing a disk image with embedded session fragments and then uses regular expressions to identify and extract these sessions. This showcases a simplified version of how tools might reconstruct valuable data from raw disk reads.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
